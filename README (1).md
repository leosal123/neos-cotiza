# Propuesta de ejemplo

`propuesta-ejemplo.pdf` muestra una cotización ficticia generada con Neos Cotiza y revisada en A4. Incluye el logo original de Neos Linx, desglose, total, condiciones y numeración de página.

El negocio de ejemplo y sus importes son ilustrativos. No es una oferta comercial ni contiene datos de un cliente real.

Para producir tu propia propuesta, ejecuta la app, configura el proyecto y abre **Revisar propuesta → Imprimir / Guardar PDF**. En Chrome selecciona A4, escala 100% y desactiva los encabezados y pies automáticos del navegador para evitar que añada fecha o URL.

El PDF de esta carpeta es el único ejemplo de propuesta admitido por el empaquetador. Las cotizaciones privadas, descargas personales y borradores deben mantenerse fuera del repositorio.
